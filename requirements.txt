# End-to-End Automated Seismic Processing Pipeline -- Python dependencies
# for every stage (prepro, pick, association, locator, relocation, magnitud, focmech).
#
# One venv is enough: the picking stage's SeisBench/torch stack and the
# association/location/relocation/magnitude stack were previously kept in
# two separate conda envs, but both stacks are confirmed to coexist in one
# environment (this project's own 'obspy' conda env already has pyocto
# installed alongside torch/seisbench with no conflict) -- pinned here as one
# list. Install with:
#   python -m venv .venv && source .venv/bin/activate
#   pip install -r requirements.txt
#
# Two Python packages below need an external, non-pip prerequisite -- see
# README.md's Install section:
#   - torch:  installs a CPU build from plain PyPI. For the CUDA 12.1 build
#     this project was validated on, install instead with:
#       pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
#   - pygmt:  wraps the GMT C library, which is not on PyPI. Install GMT
#     first (e.g. `sudo apt install gmt` or `conda install -c conda-forge gmt`),
#     then `pip install pygmt` will find it.
